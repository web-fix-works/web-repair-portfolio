Case 01｜レスポンシブ改修と印刷レイアウト

対象サイト： Fieldnotes（コンセプトサイト）
技術： HTML / CSS / JavaScript / Print CSS

課題とアプローチ

PC向けの固定幅レイアウトをそのまま縮小すると、スマートフォンでは横スクロールや文字のはみ出しが発生します。改善前ページと改善後ページを用意し、表示幅に応じた再配置と情報の読みやすさを比較できる形にしました。

  • 改善後のサイトを見る
  • 改善前の状態を見る

対応内容

  • コンテンツ幅を可変にし、minmax(0, 1fr) とメディアクエリで要素を再配置。
  • 見出しと本文の文字サイズに clamp() を適用し、狭い画面でも読みやすい余白を維持。
  • スキップリンク、可視フォーカス、意味のある見出し階層、日時・表のマークアップを整備。
  • 印刷専用CSSを分離し、ナビゲーションや装飾を省き、利用案内・本文・所在地を保持。
  • FAQはネイティブの <details> を採用。印刷時のみ全回答を展開し、印刷終了後に元の開閉状態へ復元。
  • prefers-reduced-motion に応じてアニメーションを抑制。

設計判断

判断 目的
固定幅から可変幅へ 画面外への情報のはみ出しを抑え、縮小・拡大表示への耐性を高める。
文章と装飾を分離 イラストや背景が使えない場合でも必要な情報を取得できるようにする。
ネイティブのFAQ要素を採用 過度なJavaScriptと独自のキーボード処理を避け、基本操作を単純化する。
印刷スタイルを画面用から分離 用紙上で不要なUIを除き、必要な情報を読みやすく配置する。

確認したい操作

  1. 320px〜大画面で表示し、情報の重なり・横スクロールの有無を確認。
  2. Tabキーで主要なリンクに移動し、フォーカスの表示を確認。
  3. FAQを開閉してから印刷プレビューを開き、回答の掲載と開閉状態の復元を確認。
