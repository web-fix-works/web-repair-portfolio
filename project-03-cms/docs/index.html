Case 03｜XML・XSLTによるCMSテンプレート設計

対象サイト： SAMPLE COMPANY Corporate Newsroom（コンセプトサイト）
技術： XML / XSLT 1.0 / Python / HTML / CSS / Print CSS

課題とアプローチ

記事一覧と詳細ページを個別に更新する運用では、記事の重複や情報の不一致が発生しやすくなります。本作品ではXMLを記事情報の管理元とし、XSLTテンプレートから一覧・カテゴリ別一覧・詳細ページを生成する方式を採用しました。

  • 企業サイトを見る

構成

data/articles.xml → templates/list.xsl / templates/detail.xsl → scripts/build.py → site/

対応内容

  • 公開日による新着順表示、カテゴリ分類、4件単位のページネーション。
  • 記事のパンくず、日付の機械可読なマークアップ、関連記事の導線。
  • ページごとのタイトル・説明文と記事本文の適切な見出し構造。
  • XMLのカテゴリ・日付・識別子の入力チェック、古い生成ファイルの整理。
  • 記事を印刷する際に本文・日付・タイトルを保持する専用CSS。
  • 外部リソースに依存せず、記事本文を静的HTMLとして提供。

設計判断

判断 目的
記事データと表示を分離 見出しや日付を複数ページで二重管理しない。
XSLT 1.0を使用 XMLの抽出・並び替え・テンプレート変換を明確に分ける。
静的HTMLとして出力 JavaScriptに依存せず記事へのリンクと本文を表示できるようにする。
ビルド前にデータ検証 不正なカテゴリや重複する識別子でページを生成しない。
印刷時に本文を優先 ナビゲーションを除去し、出典・見出し・日付・本文を残す。

ソース構成

  • data/articles.xml：記事データ
  • templates/list.xsl：一覧・カテゴリページ
  • templates/detail.xsl：記事詳細
  • scripts/build.py：変換と生成処理
  • site/：生成したHTML

※本作品はCMSテンプレート技術を示すための自主制作サンプルであり、特定の商用CMS製品の実装ではありません。
