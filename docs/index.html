制作・実装の概要

既存Webサイトの修正・改修で求められる、表示・操作・更新運用の3つの観点をテーマにした制作作品集です。各作品は実際に操作できるサイトと、設計内容がわかる技術解説で構成しています。

設計で重視したこと

画面幅と操作環境への適応

固定幅に依存しないレイアウト、見出し構造、可視フォーカス、キーボード操作を組み合わせて、さまざまな環境で情報に到達しやすい構造を採用しています。

印刷・PDF保存

紙面では画面上のナビゲーションや装飾を整理し、利用案内や記事本文を残します。FAQのような開閉式コンテンツは、印刷前後で表示状態を制御しています。

変更しやすい構成

データと表示の分離、HTMLの意味付け、部品単位のCSS、既存の操作を妨げにくいJavaScriptを意識しています。CMS作品では記事XMLからHTMLを生成します。

使用技術

HTML / CSS / JavaScript / XML / XSLT 1.0 / Python（静的サイト生成）
