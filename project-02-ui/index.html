アカウントについて

登録情報やログインに関するご案内

ログインができません

入力しているメールアドレスとパスワードをご確認ください。ブラウザの保存情報が古い場合は、再入力をお試しください。

繰り返し失敗する場合は、入力情報を確認し、しばらく時間をおいてお試しください。

パスワードを忘れました

パスワード再設定の案内メールが届かないときは、迷惑メールフォルダと登録メールアドレスをご確認ください。

登録情報を変更したいです

プロフィール編集画面で変更できる項目を明記し、保存時には成功・失敗を通知する設計が必要です。

退会したい場合はどうすればよいですか？

退会時に削除されるデータ、保持されるデータ、復旧可否を事前に提示する必要があります。

▤

ご利用プランについて

請求・変更・契約に関するご案内

プランは途中から変更できますか？

プラン変更に伴う料金の反映時期は、選択したプランとお支払い状況によって異なります。お申し込み内容をご確認ください。

請求書・領収書はどこから確認できますか？

アカウントの請求履歴から確認できる設計を想定しています。適格請求書の要件などは事業内容に応じて検討します。

支払いが完了しないときは？

カード情報の再確認に加え、エラーメッセージを利用者が次の行動を理解できる内容にすることが大切です。

自動更新を停止できますか？

継続課金を扱うサイトでは、自動更新の有無、停止期限、解約後の利用期限を明示する必要があります。

◇

セキュリティについて

安全に利用するための基本的なご案内

二段階認証を利用できますか？

二段階認証の設定は、アカウントのセキュリティ設定からご確認ください。復旧コードは安全な場所に保管してください。

不審なメールを受信しました

リンクを安易に開かず、サービスの公式サイトから情報を確認してください。被害が疑われる場合の連絡先も必要です。

共有端末でログアウトするには？

共有端末では利用後のログアウトに加え、ブラウザに資格情報を残さないことが重要です。

データはどのように保護されますか？

大切なデータは、必要な範囲でのみ共有し、個別のアカウントで管理することをおすすめします。

一致する質問はありません。別の言葉でお試しください。
